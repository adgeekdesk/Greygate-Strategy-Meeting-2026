[ Current gap ]

The Master SOP is written as though “The Projects Management System” is a live, integrated platform — driving Gantt visibility, task assignment, QC approval steps, materials tracking and job cards (Appendix B). In practice, project planning and management have been named as a sore point, which suggests this system is either not implemented, only partially used, or run in parallel with spreadsheets, WhatsApp and paper. This pillar decides how Greygate actually wants to plan and manage projects going forward, and whether a platform such as Odoo is the vehicle for it.

[ Discussion points ]
  1. 01Confirm today's real state: what, if anything, is currently used to plan projects, assign tasks and track Gantt timelines — and where it breaks down.
  2. 02Review Odoo as a candidate platform against the Appendix B requirements already defined in the Master SOP — in particular the Project, Timesheets, Inventory, Purchase, Manufacturing (MRP) and Accounting modules, which map closely onto Job Cards, task assignment, materials/QC tracking, procurement approvals and the financial reporting gap raised in Pillar 5.
  3. 03Agree whether to run a scoped pilot in one department (e.g. Workshop task assignment and Gantt) before a full rollout, versus a phased module-by-module implementation across all departments.
  4. 04Agree data and process readiness: job card templates, materials lists, QC checklists and cost tables need to be structured consistently before they can be loaded into any system — this is process work, not just software configuration.
  5. 05Name a Digital Systems Owner responsible for implementation, data migration, user training and ongoing administration — this need not be a new hire initially, but it must be a named accountability.
  6. 06Agree a realistic budget and timeline for licensing, implementation/configuration support, and staff training, and how this is sequenced against the new workshop transition.
  7. 07Agree how the platform will be adopted day-to-day — mandatory use for task assignment and QC sign-off from a set date, with the manual daily-dashboard fallback (Pillar 3) retired once the system is live.
